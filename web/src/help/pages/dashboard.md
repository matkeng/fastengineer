The Dashboard shows what is stored in the open project and gives shortcuts to the common starting points.

![The Dashboard](img/dashboard.png)

## The cards

Each card counts one kind of thing and says a little more underneath. Click a card to open that section.

| Card | Shows |
|---|---|
| Symbol libraries | Libraries and their templates |
| Drawings | Drawings added, pages, and how many are not analysed yet |
| Tags found | Tags in the latest analysis |
| List imports | Imports and file revisions |
| Project lists | Plant areas, packages, codes and so on |
| Deliverables | Deliverables and revisions issued |
| Generators | Builds and PLC panels |
| Engine | Whether the engine behind the app is running |

## Start

| Button | What it does |
|---|---|
| **Try the P&ID example** | Adds a sample drawing and the ready-made P&ID library to Symbol detection |
| **Load sample data** | Fills every list that is still empty with a small invented plant. Lists that already have data are left alone |
| **Compare tables** | Opens [Compare tables](help:compare) |
| **Analyse drawings** | Opens [Symbol detection](help:symbols-libraries) |
| **New list import** | Opens [List import](help:import-overview) |

## Recent activity and Latest analyses

**Recent activity** lists the latest uploads, saves, analyses and issued revisions. Click an entry to open it.

**Latest analyses** charts how many tags each recent analysis found, split into tags from matched symbols and tags found by the text scan. **Table** shows the same figures as a table.

## Storage & system

Where the project's data is kept, how large it is, and whether OCR is available on this computer. **Refresh** at the top re-reads everything on the page.
