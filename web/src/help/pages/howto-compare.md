Use this when someone sends a revised schedule and you need to know what changed.

## 1. Choose the old table

1. On the **Dashboard**, press **Compare tables**.
2. Drop the **old** workbook on the box.
3. Pick the sheet, the header row and the key column: the column that identifies each row, such as the cable number or tag.
4. Press **Use this table**.

![Picking the key column](img/wizard-key.png)

## 2. Choose the new table

Press **Next: new table** and do the same for the new workbook. If both revisions are sheets of one workbook, press **Use the same workbook as the old table**.

Use the **same key column** on both sides.

## 3. Compare

Press **Compare →**.

![The result](img/compare-result.png)

- The chips count the rows by status. Click one to show only those rows.
- Changed cells show `old → new`.
- **Changed columns only** hides the columns where nothing changed.

## 4. Keep a record

Press **Excel (.xlsx)** for a formatted report of what is shown: a colour-coded Differences sheet, a Cell changes sheet with one row for each change, and a Summary.

## Tips

- If many rows show as Added and Deleted, the key column is probably wrong, or the keys were renumbered.
- If struck-through rows are a deletion in your documents, leave **Strikethrough counts as a change** ticked: rows struck out in the new revision are reported as *Struck out*.
- Untick **Ignore case** only when capitals matter.
